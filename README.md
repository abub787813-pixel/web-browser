# 🌌 Epic Browser

A modern desktop web browser built with **Python, PyQt5, and QtWebEngine**, featuring a custom dark-themed homepage and a clean browsing interface.

## ✨ Features

- 🌙 Modern dark-themed browser interface
- 🎨 Custom Epic Browser homepage
- 🔍 Google search integration
- 🌐 Website URL navigation
- ▶️ Quick-access website shortcuts
- ⬅️ Back and Forward navigation
- 🔄 Reload webpage functionality
- 🏠 Custom Home button
- 📊 Website loading progress indicator
- ⌨️ Keyboard shortcuts
- 🖥️ Full-screen browsing experience

## 🛠️ Technologies Used

- Python
- PyQt5
- PyQtWebEngine
- QtWebEngine
- HTML
- CSS
- JavaScript

## 📦 Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Epic-Browser.git
```

### 2. Navigate to the project directory

```bash
cd Epic-Browser
```

### 3. Install dependencies

```bash
pip install PyQt5 PyQtWebEngine
```

### 4. Run the browser

```bash
python "web browser.py"
```

## ⌨️ Keyboard Shortcuts

| Shortcut | Function |
|---|---|
| Ctrl + L | Focus address bar |
| Ctrl + R | Reload webpage |
| Alt + Left | Go back |
| Alt + Right | Go forward |

## 🎯 Project Goal

The goal of Epic Browser is to create a simple, attractive, and user-friendly desktop browsing experience using Python and modern web technologies.
